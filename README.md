# Hi, I'm Ali

**Research · agentic tooling · open data**

I build Python backends, LangGraph agents, and small full-stack apps — mostly around GitHub automation, UK public data, and settlement/relocation Q&A.

[Build log & notes →](https://kurtc3b3.github.io) · [GitHub](https://github.com/kurtc3b3)

## Projects

| | Project | What it does |
|---|---------|--------------|
| 🤖 | [**tissue-bot**](https://github.com/kurtc3b3/tissue-bot) | Collect GitHub repo/issue data into SQLite; analyse and resolve issues with LangGraph agents (FastAPI + Next.js) |
| 🏛️ | [**policritique**](https://github.com/kurtc3b3/policritique) | Collect UK election results, MPs, and party policies for analysis |
| 🇬🇧 | [**settlr-ai**](https://github.com/kurtc3b3/settlr-ai) | Scrape UK settlement forums (Stack Exchange, Immigrationboards); draft Q&A responses with LLMs |
